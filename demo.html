PGVectorRAGIndexer is a 100% local, self-hosted document search engine. Here's what it looks like in practice — no install required to watch.

Shown against a small sample document set, not a shared live server.

Multi-Format Search

Search across PDF, Word, Excel, PowerPoint, Markdown, HTML, and plain text — all in one place.

Smart Search

Finds exact matches first. When there's no precise hit, it understands meaning — so "dog" also finds "puppy".

Document Tree & Folder-Scoped Search

Browse indexed documents in a familiar folder tree, then scope a search to just one folder — or exclude one — right from the tree.

100% Private

Everything runs on your machine. No cloud uploads, no accounts, no tracking. Your data stays yours.

Built for Teams

Deploy on a shared server — Windows, macOS, and Linux clients connect remotely. RBAC, audit logs, SSO, and per-user document visibility included.

License Stacking

Need 50+ users? Stack multiple Organization licenses on one server. The Admin Console shows total licensed seats and per-key status.
